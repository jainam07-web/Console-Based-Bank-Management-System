# Console-Based-Bank-Management-System
A simple console-based Bank Account Management System developed in Java. This project demonstrates the use of Object-Oriented Programming (OOP) concepts, ArrayList, loops, methods, and user input handling with Scanner.

Features
Create a new bank account
Deposit money into an existing account
Withdraw money from an account
Display all account details
Menu-driven console interface
Basic input validation for:
15-digit account number
10-digit phone number
Sufficient balance before withdrawal
Technologies Used
Java
Object-Oriented Programming (OOP)
ArrayList
Scanner (User Input)
